File upload from admin UI — detailed numbered flow

Scope: Standard document upload (PDF, DOCX, CSV, …) from app/frontend-admin/app/ingestion/upload/page.tsx. Not covered in the sequence diagram: external sources (RSS/web), watcher, separate media-only path — see §_branch notes below.
PDF: Print this page from Chrome/Edge. If Mermaid does not render from file://, run python -m http.server 8765 in this folder.

Config authority during ingestion:
get_client_config(client_id) in app/core/config/client_config_resolver.py loads app/core/configs/default.json (base), merges optional app/core/configs/<client_id>.{json,yaml} or configs/ at repo root, validates as ClientConfig (client_config_schema.py).
Pipeline for embedding: IngestionServiceV2._run_pipeline calls _get_ingestion_pipeline(business_id) → builds/returns embedder+vectordb (reranker/LLM stripped) via pipeline_factory.build(..., skip_cache) using that same merged config.
Async queue: If CELERY_ENABLED is true (app/worker/broker_config.py → is_celery_enabled()), HTTP returns after queueing; work continues in app/worker/tasks.py.
PII (ingestion): After chunks are built, IngestionOrchestrator supplies pre_embed_hook → sanitize_ingestion_chunks in app/services/security/ingestion_security.py (driven by ClientConfig.security.pii_middleware). IngestionServiceV2._run_pipeline applies the hook before dedup, SQL persistence of chunk text, and embedding/vector upsert. Optional audit: SecurityAuditService.log_pii_event in app/services/security/security_audit_service.py.

5 — Feature branches not expanded in the main sequence

  • Media upload (image/audio/video): file_router_v2._route_media_ingestion → MediaIngestionHookV1.handle → vision/audio pipelines; different parser map MEDIA_EXT_MAP, save under static/uploads/media.
  • External ingestion UI/API: ingest_external + route_external_ingestion / Celery run_external_ingestion_task; may read app/config/ingestion_settings.py ENABLE_LLM_NORMALIZATION.
  • Registry ingestors: route_external_ingestion can use ingestor_registry (plugin_registry.py) for connector types.
  • PHANTOM / hardware: Startup tuning via phantom_config_bridge.py in main.py lifespan affects runtime env, not each upload step directly.
  • Query-time PII / injection (user questions, not file upload): security_middleware.scan_text on routes such as retrieve_api / rag_api — separate from ingestion chunk sanitization above.
