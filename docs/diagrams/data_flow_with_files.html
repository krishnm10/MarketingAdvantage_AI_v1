A. Every authenticated admin API call (HTTP shell)

Typical path from the Next.js admin UI to a protected app/api/v2/* handler.

sequenceDiagram autonumber actor U as User participant P as app/frontend-admin/app/**/page.tsx participant MW as app/frontend-admin/middleware.ts participant AR as app/frontend-admin/lib/apiRoutes.ts participant AC as app/frontend-admin/lib/apiClient.ts participant MN as app/main.py participant RH as app/api/v2/TARGET_api.py participant DP as app/auth/deps.py participant GD as app/auth/guards.py U->>P: Click / submit form P->>MW: Navigate (Next.js request) MW-->>P: Continue (matcher may be empty) P->>AR: Build path constant AR-->>P: Return URL e.g. /api/v2/retrieve/query P->>AC: fetch(baseURL + path, Bearer token) AC->>MN: HTTPS JSON request MN->>RH: Dispatch to route handler RH->>GD: Depends(require_role(...)) e.g. retrieve_api GD->>DP: Validate JWT / user DP-->>GD: payload OK GD-->>RH: authorized admin RH-->>AC: JSON response AC-->>P: Parse body P-->>U: Update UI

C. Document ingestion — POST /api/v2/ingestion/upload

Includes tenant validation, save under static/uploads/api, DB row, then either Celery queue or inline orchestrator.

sequenceDiagram autonumber actor U as User participant UP as app/frontend-admin/app/ingestion/upload/page.tsx participant AC as app/frontend-admin/lib/apiClient.ts participant IA as app/api/v2/ingestion_api_v2.py participant TV as app/utils/tenant_validator.py participant FR as app/services/ingestion/file_router_v2.py participant SE as app/db/session_v2.py participant MD as app/db/models/ingested_file_v2.py participant ORC as app/services/ingestion/ingestion_orchestrator.py participant SVC as app/services/ingestion/ingestion_service_v2.py participant PR as e.g. pdf_parser_v2.py participant TS as app/worker/tasks.py participant BC as app/worker/broker_config.py U->>UP: Choose file + tenant UP->>AC: multipart upload + business_id AC->>IA: POST /api/v2/ingestion/upload IA->>TV: validate_tenant_id_strict(...) TV-->>IA: tenant_ctx IA->>FR: route_file_ingestion(file, business_id) FR->>FR: Stream to disk static/uploads/api/ FR->>SE: AsyncSession — dedup query SE->>MD: SELECT by file_hash + business alt duplicate MD-->>FR: existing row FR-->>IA: duplicate_skipped else new file FR->>SE: INSERT IngestedFileV2 status=uploaded SE->>MD: New file_id FR->>BC: is_celery_enabled() broker_config.py alt Celery worker path tasks.py FR->>TS: run_ingestion_pipeline.delay(...) TS-->>FR: task id FR-->>IA: JSON status queued else Inline parsers + orchestrator FR->>PR: parser_func saved_path e.g. pdf_parser_v2.py PR-->>FR: parsed_output FR->>ORC: ingest_parsed_output(...) ORC->>SVC: chunk dedup embed upsert ingestion_service_v2.py SVC-->>ORC: done FR-->>IA: JSON status ingested end end IA-->>AC: JSON AC-->>UP: Show status

D. Async ingestion continuation (Celery worker)

Starts after the API returns queued; runs in a Celery worker process (not the uvicorn web process).

sequenceDiagram autonumber participant TS as app/worker/tasks.py participant CA as app/worker/celery_app.py participant BR as Message broker e.g. Redis participant TG as app/services/ingestion/tenant_guard.py participant MAP as file_router_v2.PARSER_MAP participant ORC as app/services/ingestion/ingestion_orchestrator.py participant CFG as app/core/config/client_config_resolver.py participant SEC as app/services/security/ingestion_security.py participant SVC as app/services/ingestion/ingestion_service_v2.py participant VDB as app/core/vectordb/*.py TS->>CA: Task consumed from queue ingestion CA->>BR: Ack / transport TS->>TG: resolve_ingestion_tenant(...) TG-->>TS: tenant_ctx TS->>MAP: parser_func = PARSER_MAP[ext] MAP-->>TS: e.g. parse_pdf TS->>TS: _run(parser_func(saved_path)) TS->>ORC: IngestionOrchestrator().ingest_parsed_output(...) ORC->>CFG: get_client_config(client_id) ORC->>SEC: sanitize_ingestion_chunks(...) ORC->>SVC: IngestionServiceV2 pipeline SVC->>VDB: Upsert vectors + metadata VDB-->>SVC: OK SVC-->>ORC: complete ORC-->>TS: success TS->>TS: Dispose DB pool cache_clear pipelines per tasks.py

F. Pluggable RAG — POST /api/v2/rag/query

Router is mounted under main with prefix from rag router; uses pipeline_factory and rag_pipeline stack.

sequenceDiagram autonumber actor U as User participant AC as lib/apiClient.ts participant RA as app/api/v2/rag_api.py participant TV as app/utils/tenant_validator.py participant SM as app/middleware/security_middleware.py participant PF as app/core/pipeline_factory.py participant CR as app/core/config/client_config_resolver.py participant RP as app/core/rag_pipeline.py (built pipeline.query) participant VDB as app/core/vectordb/*.py participant LLM as app/core/llms/* U->>AC: RAG query + client_id AC->>RA: POST /api/v2/rag/query RA->>TV: validate_tenant_id RA->>SM: scan_text (injection / PII) RA->>PF: get_cached(tenant) or build alt cache miss RA->>CR: get_client_config(tenant) CR-->>RA: ClientConfig RA->>PF: pipeline_factory.build(config) end PF-->>RA: pipeline object RA->>RP: pipeline.query(sanitized_query, ...) RP->>VDB: Retrieve context RP->>LLM: Generate answer LLM-->>RP: text RP-->>RA: RAGQueryResponse RA-->>AC: JSON
